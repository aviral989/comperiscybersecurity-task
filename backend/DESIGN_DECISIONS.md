# Backend GraphQL API Design Decisions (Task 2.1)

### Context & Architectural Objectives
The backend API was architected to support enterprise multi-tenancy, high-volume board rendering, and deterministic real-time filtering for task management without unbounded memory consumption or cross-tenant data leakage.

### 1. Cursor-Based Keyset Pagination over Offset Paging
Rather than implementing standard `limit`/`offset`—which suffers from linear \(O(N)\) degradation as users scroll through thousands of project tasks—we engineered keyset cursor pagination conforming to the Relay Connection specification (`edges`, `pageInfo`, `cursor`, `endCursor`). Cursors are generated by base64-encoding compound keys `(task.id, task.orderInStatus)` or `(task.createdAt, task.id)`. This provides strict \(O(1)\) pagination guarantees, avoids "page drift" when tasks are inserted concurrently, and maintains stable card ordering during infinite scroll.

### 2. Multi-Tenant Context & RBAC Authorization
Tenant isolation is enforced before resolver dispatch via custom middleware (`buildAuthContext`). The middleware parses incoming tenant (`x-tenant-id`) and user credentials (`x-user-id`), validating active organization membership. If a user attempts to query a project belonging to another tenant or lacks required permissions (e.g., a `VIEWER` attempting a `createTask` or `moveTaskStatus` mutation), execution is aborted immediately with structured `FORBIDDEN` GraphQL errors. Every database query is strictly scoped by `organizationId`.

### 3. Server-Side Composite Filtering & Summary Aggregations
To prevent client-side data overfetching, the `tasks` query supports compound server-side filters: multi-status IDs, assignee ID, priority arrays, date ranges, and full-text keyword matching across titles and descriptions. In parallel, the `taskSummary` query provides high-speed KPI rollups (overdue counts, status distribution, priority ratios) in a single round-trip, decoupling executive dashboard metrics from raw task list payloads and enabling instant board header rendering.
